# Fulton Linux / Steam Deck test list (1.56)

Needs a Linux PC or a Steam Deck (Desktop Mode). About 20 minutes.

## Get Fulton
- [ ] Get `Fulton-1.56.0-linux-x64.AppImage` from the GitHub Actions run (Artifacts → fulton-linux).
- [ ] Right-click → Properties → Permissions → **Allow executing as a program** (or `chmod +x`), then double-click it. Fulton opens.
- [ ] (Alternative) Unzip the source, open a terminal in the folder, run `./Start Fulton.sh`.

## Basics
- [ ] Window looks right: fonts, covers, sidebar, Customize, Support button.
- [ ] Controller works (Deck buttons move around, shoulder buttons change pages).
- [ ] Find more: choose **Download for: Linux** if shown, or pick a port that has a Linux build.
- [ ] Install a port with a Linux download (e.g. a Harbour Masters game). It installs, shows as installed, and **Play** starts it.
- [ ] A Windows-only port says it has no Linux download yet (no crash).
- [ ] ROM: add a ROM folder; the game finds its ROM.

## Steam Deck
- [ ] Add to Steam works and the game appears in Steam after a restart.
- [ ] Does it run in Desktop Mode? Does it open from Game Mode (as a non-Steam game)?

## Send back
- Screenshots of anything odd and the **Report a problem** zip from Settings.
